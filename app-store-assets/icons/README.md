# PitchReady App Icon Assets

Approved production icon assets live in `assets/branding/approved-icon/`.

Those source files are mirrored into the active Expo asset paths:
- `assets/images/icon.png`
- `assets/images/favicon.png`
- `assets/images/android-icon-foreground.png`
- `assets/images/android-icon-background.png`
- `assets/images/android-icon-monochrome.png`

The iOS export-ready app icon set is stored in:
- `app-store-assets/icons/ios/AppIcon.appiconset/`
